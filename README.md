## The entry

`main.ts` writes exactly two lines to `/output/entry.txt`:

> Don't laugh when your little sister holds up the lopsided cake she baked for Mum's birthday on the kitchen floor at six o'clock.
>
> That laugh is why she never bakes again, and her baking is the one thing that still brings the whole family to the same table.

Line one warns the past self about one specific, picturable moment — a time (six o'clock), a place (the kitchen floor), a person (little sister), an object (a lopsided birthday cake) — in a single sentence. Line two traces the cause and effect in one sentence: the laugh ends her baking, and her baking is what gathers the family.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4; TypeScript runs as-is):

```sh
node main.ts
```

This writes `/output/entry.txt` (256 characters, 2 lines, inside the 1–280 character gate). Set `OUTPUT_PATH` to write elsewhere when testing locally.
